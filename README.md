# Thread Lighty — Promotional Storefront HTML Email

A custom-coded, responsive promotional storefront email built from scratch for **Thread Lighty**. This project demonstrates rock-solid email architecture designed to render consistently across modern webmail clients, mobile devices, and legacy desktop environments.

## 🛠️ Built With
* **Raw HTML Tables:** Nested table-based architecture for dependable alignment and spacing across strict rendering engines like Microsoft Outlook.
* **Inline CSS:** Direct inline styling to prevent email clients from stripping out `<style>` tags.
* **Responsive Media Queries:** Mobile-first breakpoints to stack multi-column product grids and optimize typography on smaller screens.

## ✅ Testing & Compatibility
* Structured to support major email clients including **Gmail, Apple Mail, Outlook, and Yahoo Mail**.
* Tested across desktop and mobile viewports to ensure clean image scaling.
